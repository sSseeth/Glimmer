# Code of conduct

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

- Be kind and assume good faith.
- Critique code, not people.
- No harassment, discrimination or personal attacks, in any project space.
- Respect people's privacy. Never share someone else's diary content, logs
  or personal details.

Report problems privately to the maintainer through GitHub. Reports are kept
confidential. The maintainer may remove comments, commits or contributors
that break these rules.
